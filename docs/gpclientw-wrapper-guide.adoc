:toc: left

:sectlinks:
:sectanchors:

A comprehensive Python wrapper for the GlobalProtect OpenConnect client that simplifies VPN connections,
handles version compatibility issues, and provides multiple connection modes.

== Overview

The `gpclientw.py` wrapper is a unified solution that combines the functionality of
multiple connection scripts into a single, powerful tool.
It automatically handles version compatibility issues,
provides HIP (Host Integrity Protection) support, and
offers multiple connection modes for different use cases.

=== Key Features

*  *Automatic Version Override*: Fixes "Please ensure the compatible GlobalProtect version is: 6.1.4 or above" errors
*  *HIP Report Support*: Automatic Host Integrity Protection compliance reporting
*  *Multiple Connection Modes*: User, root, and userspace modes
*  *Dynamic Gateway Selection*: Automatically selects appropriate gateways
*  *Comprehensive Error Handling*: Clear error messages and troubleshooting
*  *Status Monitoring*: Real-time VPN connection status
*  *Clean Disconnection*: Proper cleanup and process management
*  *Cross-Platform*: Works on Linux, macOS, and WSL

== Troubleshooting

=== Version Compatibility Issues

The wrapper automatically resolves these common GlobalProtect version errors:

* ❌ "Please ensure the compatible GlobalProtect version is: 6.1.4 or above"
* ❌ "CAS is not supported by the client. Minimum client version is 6.0"

*Solution*: The wrapper automatically configures both `clientVer` and `app-version` parameters with modern version numbers.

=== Connection Problems

==== Step 1: Check Status

----

== Security Considerations

=== HIP Reports and Compliance

Host Integrity Protection (HIP) reports are security assessments that:

* Submit system information for compliance verification
* Include: OS version, patch level, antivirus status, firewall configuration
* Are required by many enterprise VPN environments
* Help ensure connecting devices meet security standards

Enable HIP reporting with the `--hip` flag for compliance with organizational policies.

=== Version Spoofing

The wrapper reports a modern GlobalProtect client version (default: 6.3.0) to:

* Bypass outdated version restrictions on servers
* Ensure compatibility with modern GlobalProtect features
* Avoid "version too old" errors

This is accomplished through:

* Direct parameter modification in the gpclient code
* LD_PRELOAD override for OpenConnect integration
* No actual GlobalProtect client installation required

=== Root Privilege Handling

Root mode operates securely by:

* Performing authentication as a regular user first
* Using sudo only for VPN tunnel creation and network configuration
* Storing temporary authentication cookies with restricted permissions
* Cleaning up all temporary files after connection

== Integration and Automation

=== Shell Aliases

Add convenient aliases to your shell configuration:

[source,bash]
----
# Add to ~/.bashrc or ~/.zshrc
alias vpn-connect="python3 /path/to/gpclientw.py connect.vanderbilt.edu --hip"
alias vpn-status="python3 /path/to/gpclientw.py --status"
alias vpn-disconnect="python3 /path/to/gpclientw.py --disconnect"
----

=== Systemd Service

For automatic VPN connection at boot, create `/etc/systemd/system/vanderbilt-vpn.service`:

[source,ini]
----
[Unit]
Description=Vanderbilt VPN Connection
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/path/to/gpoc
Environment=GP_APP_VERSION=6.3.0
Environment=LD_PRELOAD=/path/to/gpoc/gp_version_override.so
ExecStart=/usr/bin/python3 /path/to/gpoc/gpclientw.py connect.vanderbilt.edu --hip
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
----

Enable and start the service:

[source,bash]
----
sudo systemctl enable vanderbilt-vpn.service
sudo systemctl start vanderbilt-vpn.service
----

=== Cron Job for Automatic Reconnection

Create a cron job to maintain VPN connectivity:

[source,bash]
----
# Add to crontab with: crontab -e
*/5 * * * * /usr/bin/python3 /path/to/gpclientw.py --status || /usr/bin/python3 /path/to/gpclientw.py connect.vanderbilt.edu --hip
----
